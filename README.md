# Discovery Workshop

**Discovery Workshop** is an independent, offline-first Flutter mobile application designed as a practical repair, maintenance, and technical reference guide.

---

## Key Features

* **System-Categorized Guides:** Structured step-by-step repair procedures and maintenance checklists organized by vehicle system (Engine, Transmission, Suspension, Brakes, Electrical, Air Conditioning, and Body).
* **Offline-First Architecture:** Built to run reliably in the workshop or garage without requiring an active internet connection.
* **Privacy-Focused:** Operates without user accounts, analytics tracking, or external data collection.

---

## Tech Stack

* **Framework:** Flutter (Dart)
* **Target Platform:** Android (Target SDK 36)
* **Local Storage:** On-device local storage / assets
